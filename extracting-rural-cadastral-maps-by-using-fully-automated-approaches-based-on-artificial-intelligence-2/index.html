Extracting Rural Cadastral Maps by Using Fully Automated Approaches Based on Artificial Intelligence

Overview

This research is based on my Master’s thesis in Land Administration Systems at Shahid Beheshti University and Subsequently it is resulted a peer-reviewed research publication in the IEEE Journal of Selected Topics in Applied Earth Observations and Remote Sensing (JSTARS).

It explores the application of Artificial Intelligence, deep learning, and high-resolution imagery for the automated segmentation of agricultural cadastral maps.

 

Abstract

Since one of the most fundamental challenges for land surveyors in Land Administration Systems is the production and updating of cadastral maps, the existence of a fully automated system that can digitize these maps using photogrammetry images would undoubtedly be very helpful. It can significantly reduce financial and human costs and expedite tasks.

Considering the emergence of deep learning models that leverage artificial intelligence for image processing and segmentation, I have undertaken to implement and execute a fully automated software equipped with a high-precision deep learning model for the production and digitization of cadastral agricultural maps.

To implement this approach, I first identified the necessary standards and common artificial intelligence models in this field. Then, by programming a fully automated approach and incorporating this model into it, I developed a program that can generate digital maps of agricultural lands solely by providing photogrammetry images. This approach consists of three main parts: image preprocessing, deep learning model processing, and image post-processing, all of which are implemented using Python programming in an open-source environment with open-source libraries and software.

One of the most important findings of this research can be the identification and utilization of the SAM model, which is one of the models for segmentation and identification of damages separately and has recently been introduced by Meta. During this research, this deep learning model was able to segment lands in some areas with an IoU accuracy of 92 percent.

In this research, it was determined that to improve the accuracy of results in such a fully automated approach, the use of Semantic Segmentation models like the U-net model is not suitable. On the other hand, to employ an Instance

Segmentation model like SAM, we need another accurate model to identify property parcels and provide a point from inside each agricultural land to the SAM so that this model can digitize only the desired parcels.

Workflow

The proposed workflow initialy was predicted in the sections of Data Preparation, Deep Learning Processing with Segmentation, and Post Processing with Image Segmentation.

However, after implementing and training a customized U-Net model specifically for my input data and processing the images with it, I realized that U-Net and other Semantic Segmentation methods were not suitable for this research, as neighboring fields could not be segmented separately by the model. Therefore, I implemented SAM (Segment Anything Model), developed by Meta (formerly Facebook), for the segmentation process.

I should add that I also tested some versions of SAM such as LangSAM and SamGeo, which their results didn’t cover all the agricultural fields on segmentation or hadn’t the result I was expecting, so I established the original SAM model like SamGeo for my application and re-implemented all codes for pre/post geospatial processing.

Methodology

01 - Data Preparation

I contaced European Space Agency for having access to their free satelite imagery for the research and they granted me their dataset access, but after considering the data I realized that the data’s resolution is not proper for rural cadastral maps and it could not result the minimum map scale accuracy, the 1:2000.

So I enrolled and requested Aerial Data from USGS.gov (United States Geological Survey) and chose some tiles of their accurate data from San Diego suburb.

As the chosen data contained infrared band and it was not a part of my research, because some fields were contain no vagetation and also I didn’t want to limit my model to the inferared band as the required input and let the user to use the system only with spectural bands (RGB), I eliminated it.

Then I rescale the images as thier resoulution were so high for a Deep Learning model. These all done while coordinate systems of the tiles should be save and transfered for new resoulution of the output spectural bands. I should add that all of these processes are through Python.

For the evaluation of the research I digitized the parcels of the tiles manually for the Ground Thruth layer to let me compare the AI Model result with a geospatial specialist result.

02 - Deep Learning Processing & Segmentation

I established the SAM model by using its pretrained weigths file. Then ran the system through a 12Gb graphic share by Google Colab and saved the output tiles with their input coordinate system as a segmented raster with randomized unique values for spectural bands of any parcel.

03 - Post Processing (Raster to Vector conversion)

The randomized value of colors of parcels helped me in this stage to vectorization the rasters and keep the neighbor parcels not merged.

04 - Evaluation

As the evaluation process needs prediction rasters (the output of the model) only in two deminssion of output pixels (0: not a field & 1: filed), I used the only red color band of the tiles and thresould them to binary output.

Then I prepared the ground truth with the same format rasters and coordinate systems of the prediction.

After all, I interseted and compared them with each other and resulted a dataset of 4 values of True Possitive, True Negative, False Possitive, and False Negative for pixels of any tile.

Results

The proposed approach demonstrated strong performance in areas where agricultural parcel boundaries were clearly identifiable.

These results demonstrate the potential of AI-based approaches for reducing manual intervention in large-scale cadastral map production.
